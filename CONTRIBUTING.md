# Contributing to DataPilot AI

Use a focused branch for each feature. Before opening a pull request, verify the dashboard with the included sample data and test these cases:

1. Uploading a valid CSV creates a dashboard.
2. Selecting a category changes the row count, all charts, and the table.
3. Reset filters restores every row.
4. Identifier columns do not become analytics charts.

Keep real customer data, API keys, and local `.env` files out of the repository.
